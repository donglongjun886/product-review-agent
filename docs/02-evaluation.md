# 评测口径

> 评测要回答的问题、三臂对比与头条口径的**需求定义**见 [01-requirements](01-requirements.md) §5；
> 评测红线以仓库 AGENTS.md 为唯一事实源，本文不重复。
> 本文写**口径细节**：臂的材料边界、事实来源、评测集构造、判卷与交叉检查、指标定义与读法、口径边界。
> 字段名、脚本参数、数据文件清单以代码与版本库为准，本文不镜像。

## 1. 三条臂

三条臂跑同一份案源、进同一套指标计算；差异只归因于**谁允许用基础输入之外的材料**，所以材料边界钉死：

| 臂 | 材料边界 | 模型 | 工具 |
|---|---|---|---|
| `rule` | 只对案件快照跑确定性初筛 | 不用 | 不用 |
| `single` | 只喂案件快照，一次直判 | 一次调用 | 不用 |
| `agent` | 案件快照 + 按证据缺口动态调查 | 多步 | 生产工具集 |

- `rule` 直接复用线上三分流：判放行记 PASS、判拒绝记 REJECT、判"复杂，需要进一步查"记 **HUMAN_REVIEW**。
  口径差异要写明：**线上复杂案交给 Agent 终裁，评测里记 HUMAN_REVIEW** —— 评测语义是"没有 Agent 时，
  复杂案只能人工"，两者不是一回事。
- `single` 不调工具、不过 Gate：它代表"没有调查能力时，模型靠案件快照能走多远"。
- `agent` 是完整调查：提假设 → 定计划 → 动态挑工具 → 多源取证（含检索）→ 复核 → 三分类决策，
  终裁必须过事实证据与 Gate 校验，不采信模型自报的假设与置信度。

三条臂都跑**生产默认预算档**，评测不覆盖档位：预算够不够用本身是被测行为，超限按生产语义转人工。
`rule` 零模型成本、确定性；`single` 与 `agent` 需要真实模型配置、有费用、非确定性。

## 2. 事实来源

评测的事实来源是**生产装配**，不另造一套评测世界：

- 商品与商家读**真 MySQL**；案例与政策走**真 RAG**（混合召回）。
- `rule` 与 `single` 只吃案件快照，不使用工具；`agent` 用生产工具集，材料可以超出案件快照。
- 三条臂共享同一份案件快照；可比性由**材料边界**保证，而不是靠复制一份数据世界。
- 依赖或检索不可用时显式失败、记为失败，不得返回空结果冒充正常。

## 3. 评测集：构造即标签，零人工标注

评测集由**生成器合成**，真值在构造的同时产生，不需要任何人工标注。

### 3.1 生成器与打标函数是两个独立实现

- **生成器**按场景分层（明确正常 / 明确违规 / 边界 / 多信号组合 / 对抗规避）造案，造案时显式输出
  **埋点清单**：本案植入了哪些语义事实（哪个词是变形品牌词、哪条商家行为是规避模式、哪个事实在快照之外
  必须调工具才能拿到）。埋点清单**对 Agent 不可见**，只进真值侧。
- **独立打标函数**（与生成器分离的第二次实现）按**冻结的规则书**，从埋点清单推导标准答案：
  期望裁决、风险类型、期望证据类型、期望工具、应引政策。
- 生成器与打标函数分离的意义：真值不是"生成器说自己造了什么"，而是"规则书对这批埋点怎么判" ——
  两次实现互相牵制，单侧的实现错误会在另一侧暴露为矛盾。
- 打标函数配单测（规则书典型情形）；标签分布不变量与矛盾检测全自动化。

### 3.2 规则书冻结

规则书（判定口径）在标注前宣布冻结；规则书变更时标签口径同步变更，重跑打标函数重出真值。
规则不变时，真值不因评测跑分回改（红线见 AGENTS.md）。

### 3.3 难例是生成器的构造维度

难例 —— 规则判不了、快照证据不足、必须多步取证才能下结论的案子 —— 是证明 Agent 增量价值的核心
（三臂对比在简单案上拉不开差距）。新口径下难例不需要人工构造：生成器按埋点清单天然知道
"哪些事实在快照之外"，**显式构造"必须工具取证才能判"的案子**并在标签中标注期望工具与期望证据。
期望工具为空的案 = 没标注，不进工具选择指标的分母。

### 3.4 取数纪律

- 进评测集的种子案不得再进 RAG 语料，否则检索会命中被考的那条；这条由测试守住。
- 旧口径评测数据随新生成器落地后整体退役（见 01 §8）。

### 3.5 考卷与练习册（holdout / dev 纪律）

- `eval_data/v3`（320 案）是**考卷（holdout）**：封存，只在里程碑跑一次，对外报告的数字以它为准。
- `eval_data/v3-dev`（160 案，同生成器、不同种子、ID 前缀 V3D）是**练习册（dev）**：
  prompt 迭代、失败归因只对着它做，可以反复看、反复跑。
- 纪律：任何"看着评测结果改 prompt / 改代码"的循环不得使用考卷，否则最终数字是过拟合的虚高。
  练习册与考卷同分布（同生成器、同场景配比），练习册上有效的改法才可迁移到考卷。
- 预算与阈值常量在任何一份上都不许拟合（红线见 AGENTS.md）；dev/holdout 拆分管的是
  prompt 与 agent 行为迭代，不是常量调参。

## 4. 判卷与交叉检查

### 4.1 判卷器是纯代码

判卷器不引入任何模型：输入是预测输出与打标函数产出的标准答案，输出是逐案比对结果
（裁决、风险类型、证据类型、工具调用、政策引用逐项比对）。判卷形态的底线见 AGENTS.md。

### 4.2 异源模型交叉检查（审计模式）

真值的残余风险是**规则书解释偏差**（打标函数把规则书读错了）。交叉检查用一个**与被测模型不同源**的
模型做独立审计：

- 它只看**规则书 + 案例文本**，**看不到埋点清单**（避免被构造侧带节奏）；
- 它独立给出裁决，与标准答案比对：
  - 一致 → 该案进入头条指标统计；
  - 分歧 → 进入**疑问篮子**：从头条指标分母剔除、单独公开。
- 它的定位是对真值质量的审计，不是第二个标注员；分歧处置的底线见 AGENTS.md。

## 5. 指标怎么算

### 5.1 头条指标：selective prediction 口径

系统的核心价值是"安全的自动化"，所以头条不问"判对了多少"，而问"自动判的那部分有多稳"：

| 指标 | 它回答什么问题 | 分母 |
|---|---|---|
| coverage（自动化覆盖率） | 多少案被自动决策（PASS / REJECT），多少转给了人工 | 全部案（剔除疑问篮子） |
| selective risk（自动决策错误率） | 自动定下来的案里错的比例 | 被自动决策的案 |
| 错误拒绝率 | 好商品被自动拒的比例（误拒 ≫ 多余转人工，不对称成本） | 真值为 PASS 的案 |

三条分母纪律：

- 引用任何指标必须说清它的分母是哪一组；不同分母的指标不得横比。
- **转人工是克制不是错误**：它不进 selective risk 的分母，只压低 coverage。
- **自动化必须和安全一起读**：只有 coverage 上升同时 selective risk 与错误拒绝率不恶化，才谈得上价值。

### 5.2 诊断层：Agent 专用指标

以下指标不进头条，用于回答"结论对了，理由对不对"（只有 `agent` 臂有意义）：

| 指标 | 它回答什么问题 | 分母 |
|---|---|---|
| 工具选择准确率 | 该调的工具调了没有 | 标注了期望工具的案 |
| 多余调用率 | 调了多少没必要的工具 | 标注了期望工具的案 |
| 风险类型命中率 | 风险类型说对了多少 | 标注了期望风险类型的案 |
| 有效取证率 | 工具调用里多少带来新证据 | 成功的工具调用（来自调查轨迹） |

期望工具 / 期望风险类型为空的案不进对应分母；这些指标是"结论对但理由错"的自动代理，不宣称替代语义判定。

### 5.3 成本与延迟

每次运行报模型调用次数、工具调用次数、token 数的均值、P50、P95，以及单案墙钟时间分布。
token 是硬数，真实调用的费用按官方价估算；延迟只在真实模型运行时才有。
目标值不预设：以首跑实测分布为基线校准并写明依据（需求见 01 §5.5）。
成本读数与人工审核成本对照呈现：调查节点成本应显著低于人工（01 §5.5）。
**预算占用率不出数** —— 记录里没有随案冻结的预算上限，硬算只能拿当前配置去套历史运行，那是伪造观测。

## 6. 第二层：无真值检查

不依赖标签的健壮性检查，与头条指标并行出数：

- **蜕变测试**：对案件做保语义扰动（改无关字段、换表述），裁决不得翻转；做风险增强扰动
  （植入规避词），裁决不得变松。
- **pass^k**：同一批案重复运行 k 次，统计裁决一致率 —— 量化"单次抽样"的不确定性有多大。
- **过程断言**：预算守住（无超限运行）、引用可解析（每条引用能找回真实条款/先例）、
  无静默降级（无空结果冒充正常的运行）。

## 7. 口径边界

- **真实模型非确定性、不可重放**：单次运行只代表那一次抽样；pass^k 给出一致性量级，但不构成重放。
  不为改分调提示词，不为跑分放宽预算档位。
- **三条臂的差异是"允许用多少基础输入之外的材料"的整体差异**，不可分解归因于"主动调查"这一项；
  工具的必要性用期望工具覆盖如实标注，期望为空的工具不做"不必要"的判定。
- **不同世界的数字不得混算或互相暗示**：桩路径与真实模型的结果、新旧口径的评测集结果，
  都不构成同一次评测的对照。
